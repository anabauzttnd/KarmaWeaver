# KarmaWeaver

KarmaWeaver is a high-performance, cloud-native platform that enables auto-scaling, feedback for scalable, multi-layered applications on modern web frameworks.

KarmaWeaver is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/KarmaWeaver.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
